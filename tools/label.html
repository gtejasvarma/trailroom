A contact sheet is a tool, not a person.

Photographers print every frame from a roll as thumbnails on one sheet, then mark the keepers with a grease pencil. This is that, for renders.

  1. Put your generated images in one folder, named identity__item__pose.png — e.g. id07__coat-wool__walking.png. Adjust the regex in the bar if you name them differently.
  2. Put the base photo for each identity in the same folder as id07__base__base.jpg — it pins to the left so you can compare identity without switching windows.
  3. Click Open folder… above. Nothing uploads; this page reads the files locally and never makes a network request.

Pass 1 — open coding. Move with J/K, mark 1 pass / 0 fail, and write what's wrong in prose in the notes box. Do not invent categories yet. Just describe.

Pass 2 — tagging. Once you've read your own notes and grouped them into a failure taxonomy, type the tags into the side panel and re-run the sheet hitting number keys. Now you have counts.

Your work saves to this browser as you go, but Export JSONL is the real artifact — that file is your labeled set, and it's what you hold your judges against.

Why sets

Cross-pose consistency only exists across four images, so the set is the unit and it gets its own verdict. PRD §10.3: ≥75% pass per image and ≥70% per complete set. Two numbers, two decisions.
